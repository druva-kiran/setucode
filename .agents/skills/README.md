# Agent Skills Directory

Place your custom agent skills here. Each skill should be in its own subdirectory with a `SKILL.md` file:

```text
.agents/skills/
  my-custom-skill/
    SKILL.md
```

### Example SKILL.md format:

```markdown
---
name: my-custom-skill
description: Brief description of what this capability does.
activation_conditions:
  - keyword1
  - trigger phrase
---
# Instructions
Step-by-step guidance for the agent when this skill is activated.

## Examples
- Example scenario 1
- Example scenario 2
```
